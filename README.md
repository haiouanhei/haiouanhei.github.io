# 🎂 生日祝福网站

一个华丽、现代的生日祝福单页网站 —— 极光背景 + 香槟金玻璃质感 + 撒花烟花 + 吹蜡烛许愿 + 打字机情书 + 内置音乐。

直接用浏览器打开 `index.html` 就能看，不需要服务器、不需要联网（联网时会自动加载更好看的中文字体）。

---

## 快速上手

```
网站/
├── index.html        ← 双击这个打开
├── css/style.css     ← 样式（一般不需要改）
├── js/config.js      ← ★ 只改这一个文件就能定制全部内容
├── js/music.js       ← 音乐引擎（内置八音盒版《生日快乐》）
└── js/main.js        ← 交互逻辑（不需要改）
```

打开 `js/config.js`，改这几项就完成了：

| 配置项 | 说明 |
| --- | --- |
| `name` | 寿星的名字 |
| `password` | ★ 开场密码，默认 `"1031"`，纯数字、几位就几个圆点 |
| `passwordHint` | 密码键盘下面的小字提示 |
| `date` | 生日日期 `"2026-11-08"`，留空则显示"今天最特别" |
| `age` | 年龄数字，留 `null` 不显示 |
| `subtitle` | 大标题下那句祝福语 |
| `candles` | 蜡烛数量（1～8） |
| `letter` | 那封信用反引号包起来，空一行分段 |
| `signature` | 信的落款 |
| `wishes` | 祝福卡片数组，想加几张加几张 |

## 换背景图

1. 在 `网站` 文件夹里新建一个 `images` 文件夹
2. 把图片放进去，比如 `images/bg.jpg`
3. `config.js` 里：
   ```js
   backgroundImage: "images/bg.jpg",
   ```
   也可以用网图：`backgroundImage: "https://example.com/bg.jpg",`

不填就是默认的极光渐变背景（也挺好看）。
建议用**横版、画面偏暗、主体不居中**的照片，文字会更清楚。

## 换音乐

- **默认**：网页现场合成的八音盒版《生日快乐》（钢琴质感 + 弦乐铺底 + 混响），不需要任何音频文件，离线可听，也没有版权问题。
- **换成自己的歌**：在 `网站` 里新建 `music` 文件夹，放 `music/song.mp3`，然后：
  ```js
  music: "music/song.mp3",
  ```
  文件读不到时会自动退回内置音乐，不会变成哑巴。

音乐默认在点"点击开启"之后播放（浏览器规定必须有一次点击才能出声），右下角圆形按钮可以随时暂停/继续。

## 页面里有什么

1. **密码锁开场** —— 输入密码（默认 `1031`）才能进，四位圆点 + 玻璃数字键盘，错了会抖动提示；电脑上直接用键盘敲数字也行
2. **大标题** —— 「生日快乐」渐变流光字 + 名字
3. **许愿（两段式）**
   - 先在**合成台**用 9 个材料摆出蛋糕配方（上排 3 桶牛奶 / 中排糖·蛋·糖 / 下排 3 个小麦），点成品格合出蛋糕
   - 合成功后合成台退场，**生日蛋糕亮起**，点蜡烛逐根吹灭 → 烟花 + "愿望已送达"
   - 吹完可以点「再合一个蛋糕」重来
4. **那封信** —— 滚动到可见时逐字打字，光标在末尾闪
5. **祝福卡片** —— 玻璃拟态卡片，鼠标移动时有 3D 倾斜
6. **页脚** —— "再放一次烟花" / 回到开头

其他细节：鼠标跟光斑、顶部滚动进度条、右下角音乐按钮（带实时律动条）、手机端自适应、`prefers-reduced-motion` 下自动减少动效。

> 合成游戏的规则和素材说明另见 `craft/README.md`（`craft/` 里还有一个可以单独打开的版本）。

## 分享给别人

- **最简单**：把整个 `网站` 文件夹压缩成 zip 发过去，对方解压后双击 `index.html`
- **想发链接**：把整个文件夹拖到 [Netlify Drop](https://app.netlify.com/drop)，几秒就能得到一个网址；或者用 GitHub Pages / Vercel 托管

> 注意：用微信/QQ 直接打开 html 文件可能被拦，压缩包或链接更靠谱。

## 小提示

- 想改成本地字体或去掉 Google 字体：删掉 `index.html` 里那两行 `<link>` 即可，会自动用系统字体
- 想调背景深浅：`css/style.css` 里 `.bg-photo` 的 `opacity: .52`
- 想调音乐音量：`js/music.js` 里 `start()` 中的 `exponentialRampToValueAtTime(0.8, ...)`，把 `0.8` 改小
